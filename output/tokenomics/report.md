# Tokenomics experiment

Generated by `scripts/tokenomics_experiment.py` from real runs of synthetic test cases (four-round conference).
Earlier measurements of the two-round panel, including the full-documents and round-2 comparisons, are kept in
`earlier_two_round_panel/`.
Prices per 1M tokens (gpt-6-luna): input $0.10, cached input $0.01, cache write $0.125, output $0.50;
input tokens include cached and cache-write tokens. Every run made fresh intake calls (no file cache).

**Caching off check:** total cached input tokens across the 4 runs = **0** (passes: nothing was read from the prompt cache).

How: a unique random string opens every request (in the instructions and as a system message), and retries are done by the app with a new string. In earlier attempts a few slow responses (45-124 s per request) still reported cached tokens, consistent with an identical request being retried upstream; as a guard, any response that still reports cached tokens is discarded and asked again with a new string. In the run reported here that was needed 0 times ($0.0000), and the gateway reported retries on 0 of 141 responses.
